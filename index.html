Network Traffic Analysis & Visualization
for Real-Time Threat Detection

A Final Year Project by GMI students, creating a real-time dashboard with IDS capabilities to detect, analyze, and visualize network threats as they happen.

Launch Dashboard

Project Features

Real-Time Packet Capture

Continuously collects and stores network packet data for live analysis.

IDS Threat Detection

Identifies suspicious events like SYN floods, UDP floods, and malformed packets.

Interactive Dashboard

A user-friendly web interface for monitoring network threats and activity.

Geo Map Visualization

Plots threat sources on a live world map to identify geographic attack patterns.

Threat Analytics

Displays interactive charts for threat types, protocol usage, and trends over time.

Secure User Authentication

Secure login and session management to restrict dashboard access.
